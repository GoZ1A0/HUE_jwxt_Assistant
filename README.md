# HUE教务助手

<img src="app/src/main/res/drawable-nodpi/app_icon.png" width="112" alt="HUE教务助手图标" />

面向河北工程大学学生的 Android 教务查询助手，将课表、自习教室、成绩绩点、调课消息和考试日程放在一起。

**当前版本：1.1.0 · Android 8.0 及以上**

[下载 1.1.0 安装包](https://github.com/GoZ1A0/HUE_jwxt_Assistant/releases/tag/v1.1.0) · [反馈问题](https://github.com/GoZ1A0/HUE_jwxt_Assistant/issues)

## 功能

- **课表首页**：左右滑动切换周次，支持本周定位、周次选择、课程详情、重叠课程与考试日期标记。
- **课表自定义**：多课表管理，背景、配色、字体、卡片高度和透明度设置；支持 WakeUp 备份导入及本应用 JSON 导入/导出。
- **空闲教室**：速查新校区基础一、二教学楼，查看连续空闲截止时间，筛选至少空闲 1/2 小时的教室；也可自行选择校区、教学楼、周次和节次。
- **成绩与绩点**：展示学校返回的官方 GPA、课程成绩、学分和单科绩点，支持学期筛选与课程搜索。
- **调课更新**：查看完整通知和新旧排课差异，确认后更新；关联副本支持手动修改冲突处理，最近更新可撤销。
- **考试与提醒**：按实际日期查看考试、考场和座位信息，提示时间冲突；可设置课程和考试提醒。课程实况的系统区域展示取决于手机支持情况。
- **登录保持**：恢复有效会话，可主动开启本机加密保存密码的自动登录。

## 使用

1. 安装 Release 中的 APK，使用教务系统账号登录，首次使用先阅读并确认隐私说明。
2. 默认进入课表。左右滑动翻周，点击课程查看详情。
3. 在“空闲教室”中速查或按条件查询自习教室。
4. 右上角“课表设置”可修改样式、管理提醒或检查教务更新。
5. 若希望启动时只看本地课表，可关闭“启动应用自动更新课表”，之后按需手动同步。
6. “我的 → 账号与自动登录”管理账号，“我的 → 隐私”查看存储、权限和数据来源说明。

## 隐私与数据来源

在线教务功能直接连接河北工程大学教务系统 `jwglxxfwpt.hebeu.edu.cn`。登录与查询会向学校发送必要的认证和会话信息；应用不向开发者自建服务器、统计或广告平台上传个人教务数据。

只有开启自动登录后才在本机保存密码；密码和会话使用 Android Keystore 支持的加密机制保存。课表、成绩缓存、自定义课表等在本机保存，并非所有本地文件都加密。通知、精确提醒和文件选择按使用功能处理。完整条款及清理范围请在应用“隐私”页面查看。

课程、成绩和考试以学校公布的数据为准；未发布的内容显示未公布。空闲教室查询表示对应教学时段没有排课，不代表现场一定无人。此应用由个人独立开发，不是学校官方应用。

## 从源码构建

环境：JDK 21、Android SDK Platform 36、Build Tools 36.0.0。项目使用 Kotlin、Jetpack Compose / Material 3、Coroutines、DataStore、OkHttp 和 jsoup。

配置本机 Android SDK 路径后，在项目根目录运行：

```bash
# macOS / Linux
./gradlew :app:assembleDebug
```

```powershell
# Windows
.\gradlew.bat :app:assembleDebug
```

生成文件：`app/build/outputs/apk/debug/app-debug.apk`。发布包与本机自行构建包的签名由对应构建环境决定。
